# Shining Helix character designs (final)

Overworld sprite sheets for every custom character. These are the approved final looks.
Use them as the reference when making 64x64 GBA battle (front) pictures.

- Files are numbered in roster order (01-08 gym leaders, 09-12 Elite Four, 13 champion, etc.).
- Some sheets are built on the Eevee Expo overworld pack by Poltergeist / Coffee Cup — credit them.
- Not used by the build; reference only.

## Gym leader battle pictures (64x64, 16 colors)

In `graphics/trainers/front_pics/leader_*.png` with palettes in `graphics/trainers/palettes/leader_*.pal`.
Each one is edited (recolored and changed to match the design above) from a trainer sprite. Most bases come from the
**Neon Skylar** DS-to-GBA trainer sprite pack; Gideon, Tobias and Venessa use Black/White sprites supplied by the project owner,
shrunk from 80x80 to 64x64. Every leader uses a different base:
